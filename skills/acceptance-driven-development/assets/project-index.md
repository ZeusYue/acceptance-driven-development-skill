# Project Index

> Generated by Dataview from project-document frontmatter anywhere in the current vault. Non-Obsidian hosts should scan project documents directly instead of using this file.

---

## All Projects

```dataview
TABLE date, status, tags
FROM ""
WHERE template = "project-doc" AND (contains(tags, "项目") OR contains(tags, "project"))
SORT date DESC
```

---

## By Tech Stack

### C++ / Qt

```dataview
TABLE status
FROM ""
WHERE template = "project-doc" AND contains(tags, "Qt") AND (contains(tags, "项目") OR contains(tags, "project"))
SORT file.name ASC
```

---

## By Status

### Active / Maintained

```dataview
TABLE tags
FROM ""
WHERE template = "project-doc" AND (status = "开发中" OR status = "维护中" OR status = "active" OR status = "maintained") AND (contains(tags, "项目") OR contains(tags, "project"))
```

## Recently Modified

```dataview
TABLE file.mtime as "Last Modified"
FROM ""
WHERE template = "project-doc" AND (contains(tags, "项目") OR contains(tags, "project"))
SORT file.mtime DESC
LIMIT 10
```
